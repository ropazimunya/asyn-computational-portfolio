# Methods and Evidence Limits

## Three evidence classes

1. Independently executed public software tests and read-only record comparisons.
2. Historical derived scientific tables and investigation reports whose raw inputs are incomplete.
3. Retrospective educational QA, risk and regulatory documentation constructed for this portfolio.

The claim matrix records these distinctions. Neither a prior audit narrative nor a matching checksum is treated as proof that its scientific conclusion is correct.

## Scientific-source inspection

A supplied scientific ZIP contained 189 files and 33 directory entries. Source records support a numerical comparison of 24 primary log scores, pose remarks and summary entries. This comparison does not run docking, interpret affinity or reproduce preparation. Molecular outputs and their numerical structural datasets are excluded from this distribution; a source hash identifies the private evidence examined.

The scientific ZIP contains model-0 coordinate files but not complete five-model ensembles or confidence JSON inputs. No MD trajectories, original setup/production scripts or complete ligand reconstruction scripts were present. Geometric error reports and simulation interpretations therefore have historical rather than independently reproduced status.

## Software method

The auditor reads the documented ZIP layout without extracting it, hashes members, validates selected numeric fields, compares scores and records exceptions. Ligand files are inventory placeholders; their chemistry, molecular identity, atomic coordinates and nonempty content are not validated. Receptors, molecular dynamics, clinical performance and execution authenticity are not checked.

[Software input specification](../qa_auditor/INPUT_SPECIFICATION.md) defines accepted fields and policies. [Validation report](../qa_auditor/VALIDATION_REPORT.md) records the tested environment. Runtime tests were executed on Linux/Python 3.12; a CI matrix is provided for other environments but no unobserved CI run is claimed.

## Interpretation limits

A predicted interface is not an experimentally observed dimer. A geometric cavity is not evidence of dynamic cryptic-pocket opening. A confidence score is not thermodynamic stability. Matching docking records do not demonstrate ligand binding. Single short trajectories do not establish a causal ligand effect. Synthetic fault detection does not establish real-world sensitivity or regulated-system validation.

This project has no formal supervisor, clinical validation, FDA submission, GMP qualification or institutional endorsement. Researcher ownership of scientific decisions is distinct from the disclosed use of AI assistance.
